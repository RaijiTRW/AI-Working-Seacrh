### Концепция дизайна: «Интеллектуальный помощник»

Новый дизайн преобразует страницу поиска в более интерактивный, диалоговый интерфейс. Вместо простой строки поиска пользователи будут взаимодействовать с AI-помощником.

**Ключевые особенности:**

1.  **Диалоговый поиск:** Выдающаяся строка поиска полной ширины, которая предлагает пользователям задавать вопросы на естественном языке (например, «Найди мне удаленную работу в финтехе с зарплатой более 150 000 долларов»).
2.  **Динамические результаты:** Результаты поиска будут обновляться в реальном времени по мере ввода текста пользователем, при этом наиболее релевантные совпадения будут отображаться первыми.
3.  **Панель аналитики AI:** Боковая панель, которая предоставляет контекстную информацию о результатах поиска. Она может включать:
    *   **Анализ зарплат:** Оценочный диапазон зарплат для искомой роли на основе рыночных данных.
    *   **Соответствие навыков:** Визуализация, показывающая, как навыки пользователя (если профиль существует) соответствуют требованиям к вакансии.
    *   **Информация о компаниях:** Краткие факты о компаниях в результатах поиска (размер, финансирование, культура).
4.  **Современный и чистый пользовательский интерфейс:** Минималистичная эстетика с темной темой, использующая акценты синего и фиолетового для создания футуристического, ориентированного на технологии вида. Мы будем использовать четкую типографику и много свободного пространства для обеспечения читаемости.

### План реализации

Вот пошаговый план по воплощению этого дизайна в жизнь:

1.  **Создание новых компонентов пользовательского интерфейса:**
    *   Я создам новый набор компонентов React для интерфейса AI-поиска в новой директории: `src/components/ai_search/`.
    *   Сюда войдут `ConversationalSearchBar.tsx`, `DynamicResultsList.tsx` и `AIInsightsPanel.tsx`.

2.  **Разработка новой страницы:**
    *   Я создам новую страницу по адресу `src/app/ai-search/page.tsx` для размещения нового дизайна. Это позволит отделить ее от существующего приложения на время разработки.

3.  **Стилизация с помощью Tailwind CSS:**
    *   Я стилизую все новые компоненты с использованием Tailwind CSS, реализуя темную тему и новую цветовую палитру. Пользовательские стили при необходимости будут добавлены в `src/app/globals.css`.

4.  **Интеграция с бэкэнд API:**
    *   Я изучу `src/lib/api.ts`, чтобы понять, как получать результаты поиска из вашего бэкэнда.
    *   Я подключу новые компоненты поиска к существующим конечным точкам API для предоставления данных в реальном времени.

5.  **Добавление интерактивности:**
    *   Я буду использовать управление состоянием React и хуки для создания бесшовного, интерактивного опыта, включая обновления поиска в реальном времени и динамический контент в панели аналитики.
